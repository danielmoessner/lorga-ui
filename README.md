# lorga-ui

Lorga UI is a Vue 3 component library with a playground app and docs site.

## Workspace

- `packages/ui`: publishable npm package (`lorga-ui`)
- `apps/playground`: local demo app
- `apps/docs`: VitePress docs

## Commands

- `npm run dev`: start playground
- `npm run build`: build library package
- `npm run test`: run library tests
- `npm run docs:dev`: start docs
- `npm run docs:build`: build docs
- `npm run publish-to-npm`: publish library package
